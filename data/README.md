# 本地数据目录

工作台在 `TRACELENS_DATA_DIR` 下保存轨迹、任务、人工复核、模型连接和运行产物。示例配置使用 `data/production/`。验证时可以指定独立目录，例如 `data/validation/`。

仓库提供固定的数据选择、上游版本和生成脚本。首次使用时在本地生成所需数据。

- 验证上传与诊断流程可下载 20 条固定官方样例，见[启动与验证说明](../README.md#验证)。
- 评估关键失败步骤定位准确率可生成 684 条完整版、200 条精简版或 100 条历史精简版，见[数据集复现与评分说明](../docs/rsi-evaluation.md#复现划分)。
